## ⚙️ Installation

No build tools, package managers, or dependencies required.

1. **Clone the repository**
```bash
   git clone https://github.com/raunak18904/color-palette-generator.git
```

2. **Navigate into the project folder**
```bash
   cd color-palette-generator
```

3. **Open in your browser**
   - Simply double-click `index.html`, **or**
   - Use a local development server (recommended), e.g. with the VS Code **Live Server** extension, or:
```bash
     npx server .
```

That's it — no `npm install`, no build step.

---

## 🚀 Usage

1. **Generate a palette** — Click the **Generate Palette** button to create five new random colors.
2. **Lock a color** — Click the lock icon on any card to preserve that color; locked colors won't change on the next generation.
3. **Copy a HEX code** — Click any HEX value to copy it to your clipboard; a toast notification confirms the copy.
4. **Toggle dark mode** — Click the theme icon in the top-right corner to switch between light and dark themes. Your preference is remembered on your next visit.

## 🗺️ Roadmap / Future Improvements

This project was architected with extensibility in mind. Planned and potential future features include:

- [x] Lock individual colors
- [x] Dark mode with persisted preference
- [ ] **Favorite Palettes** — Save palettes to Local Storage
- [ ] **Palette History** — Browse previously generated palettes with Undo/Redo
- [ ] **Export Palette** — Download as JSON, TXT, CSS variables, or PNG image
- [ ] **Search by HEX / RGB** — Find palettes matching a specific color
- [ ] **Keyboard Shortcuts** — `Space` to generate, `C` to copy all, `D` to toggle dark mode
- [ ] **AI-Generated Palettes** — Generate palettes from prompts like *"Ocean"*, *"Sunset"*, or *"Cyberpunk"* using an LLM API
- [ ] **Color Harmony Modes** — Complementary, analogous, triadic, and monochromatic generation modes
- [ ] **Accessibility Contrast Checker** — Show contrast ratios between colors in a palette
