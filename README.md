# 🎨 Color Palette Generator

A modern and responsive **Color Palette Generator** built using **HTML, CSS, and Vanilla JavaScript**. It helps users generate beautiful random color palettes, copy HEX codes with one click, lock favorite colors while generating new palettes, and switch between light and dark themes.

This project was built as part of my frontend development portfolio to practice modern UI design, JavaScript DOM manipulation, responsive layouts, and Git version control.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/raunak18904/color-palette-generator.git
```

Move into the project directory:

```bash
cd color-palette-generator
```

Open the project using any of the following methods:

* Double-click `index.html`
* Open with the VS Code **Live Server** extension
* Use a local development server

No dependencies or package installation are required.

---

## 🚀 Usage

1. Open the application.
2. Click **Generate Palette** to create five new random colors.
3. Click any HEX code to copy it to your clipboard.
4. Lock any color to keep it while generating new palettes.
5. Toggle between light and dark mode using the theme button.
